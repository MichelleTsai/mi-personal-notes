這一版不是固定分析某家公司，而是保留架構與欄位，讓你之後換任何標的都可以直接填。

怎麼使用

先分類，再填數字
先把公司分成：護城河型、景氣循環型、高槓桿型、轉機型。分類不同，後面判讀重點也會不同。

護城河型

看獲利率與現金流能否長期穩住。

景氣循環型

看庫存、價格與獲利率是不是在高點。

高槓桿型

先看會不會爆，再看能不能賺。

轉機型

看數字是否已經連續改善，而不是只好一季。

建議用法：左邊放你要研究的公司，右邊放一個基準組。比如「台積電 vs 研究公司」或「同業 A vs 同業 B」。

安全檢查

先確認不會爆
負債比率 = 總負債 ÷ 總資產　|　流動比率 = 流動資產 ÷ 流動負債
指標公司 A公司 B判讀標準你的結論
負債比率填數值填數值<40% 安全；40–60% 中性；>60% 危險例如：A 比較保守
槓桿倍數填數值填數值製造業常見 1.5–3x；過高要小心例如：B 槓桿較高
流動比率填數值填數值<100% 壓力大；120–200% 舒適；>200% 寬鬆例如：A 短期安全
這一段只回答一件事：公司能不能先活過景氣或壓力期？

獲利檢查

再確認是不是有真賺
毛利率 = 毛利 ÷ 營收　|　營業利益率 = 營業利益 ÷ 營收　|　淨利率 = 稅後淨利 ÷ 營收
指標公司 A公司 B你該問的問題
毛利率填數值填數值高毛利是長期護城河，還是短期價格大漲？
營業利益率填數值填數值本業獲利能力有沒有維持住？
淨利率填數值填數值是不是有靠業外或匯兌支撐？
現金流對淨利比填數值填數值>100% 品質佳；長期 <80% 要小心
最重要的一句：高獲利率不等於高品質，要看它能不能連續維持。

效率檢查

最後看現金有沒有卡住
DSO = 90 ÷ 應收帳款週轉率　|　DIO = 90 ÷ 存貨週轉率　|　營運週轉天數 = DSO + DIO
指標公司 A公司 B越少代表越多代表
DSO填數值填數值收款快客戶拖款、現金回收慢
DIO填數值填數值庫存周轉快庫存堆高、需求轉弱
營運週轉天數填數值填數值現金效率高現金卡在營運中更久
如果是記憶體、面板、鋼鐵、航運這種景氣循環型，DIO 的重要性通常會非常高。

判語模板

最後寫成一段話
判語範本：
「公司名稱 的財務結構 偏保守 / 偏積極，負債比率約 數值、流動比率約 數值，短期償債 無虞 / 需留意；獲利面上，毛利率 / 營業利益率 / 淨利率 維持高檔 / 正在下滑，代表 產品力強 / 面臨價格壓力。若從營運效率來看，DSO / DIO / 營運週轉天數 改善 / 惡化，顯示現金回收 更順 / 被卡住。整體而言，這家公司目前更像是 高品質穩健型 / 景氣循環高點型 / 轉機初期型。」
你之後只要把空格填完，就等於完成一篇有脈絡的基本面分析。
